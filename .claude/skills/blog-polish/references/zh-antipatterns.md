# Chinese Anti-Patterns Reference (中文反模式)

中文版的核心问题不是 "AI 通用味"，而是 **机器翻译腔（machine-translation stiffness）**——直接从英文句式照搬到中文。这些规则专门针对这个问题。

先把句子放回整段，看看哪里真的不顺，再决定要不要改。作者的原意和声音样本优先；词频、句长和标点只能提示问题，不是改稿配额。通顺的地方可以不动。

## 1. 代词链 / Pronoun chains

**英文需要 "you, your, the, it"，中文不需要。**

中文会大量省略代词。"你向你大脑宣告的是" 是直译，原生中文会说 "你其实是在告诉自己"。

| 翻译腔 ❌ | 原生中文 ✅ |
|---|---|
| 你向你的大脑宣告的是 | 你其实是在告诉自己 / 你这是在跟自己说 |
| 它会自动跑反馈回路把你拉回这个目标上 | 它会自动跑反馈循环，把你拽回这个目标 |
| 当你说"我想要 X"的时候 | 你说"我想要 X"的时候 |
| 你的大脑会主动给你制造阻力 | 大脑会主动给你制造阻力 |

**Rule:** 看代词是否重复、指代是否清楚。删后若改变视角、归属或口气，就保留；不要为了减少代词而抹掉作者本人。

## 2. 主从结构 / Long nested sentences

**先看主干与修饰关系，不默认短句更自然。**

定语太长、条件离动作太远，或读到后面已记不清前面说什么时，再调整语序或拆句。多个“的”和多层从句值得看一眼，但数量本身不构成重写理由。

| 翻译腔 ❌ | 原生中文 ✅ |
|---|---|
| 这是一个挺复杂的、与你的过去经历有关的、需要花时间消化的问题。 | 这事跟你过去的经历有关，挺复杂，得花时间消化。|
| 当我意识到我之前一直在用错误的方式思考这件事的时候，我才发现我浪费了很多时间。 | 我发现自己一直想错了，也浪费了很多时间。|

**Rule:** 改善读者理解，不按“的”或分句数量拆句。拆后核对条件、否定和限定仍然管着原来的内容。

## 3. 语气词 / Modal particles

吧/啊/嘛/呢/了/吗可以承载口气，但没有语气词的段落也可以是自然中文。先看原话的迟疑、强调、改口和停顿，不为“显得像聊天”补口气或心理。

常用语气词及功能：
- **了** — 完成、变化（"它就漂回去了"）
- **吧** — 缓和、建议（"先这样试试吧"）
- **啊** — 感叹、亲近（"挺玄的啊"）
- **嘛** — 解释、不耐烦（"我就 i 人嘛"）
- **呢** — 疑问、对比（"你呢？"）
- **吗** — 是非问

**Rule:** 没有最低数量。保留承担语气或意思的虚词；只有符合原意和作者口吻时才补，不给每段配一个。

## 4. 破折号 / Avoid em-dashes

**正文默认不用破折号（——）。** Zach 明确表示不喜欢 AI 写作里使用破折号，不符合他的写作习惯（2026-11-26）。除非原文引语里自带，否则一律改用更自然的中文标点：

- **冒号（：）** — 引出解释或例子
- **句号（。）** — 直接断句，更干脆
- **逗号（，）** — 顺接补充
- **中文括号（（））** — 简短插注

| 破折号 ❌ | 原生中文 ✅ |
|---|---|
| 客气但干脆地拒绝，不算当“鹰”——模型里的鹰，是真准备掀桌子、扛损失的。 | 客气但干脆地拒绝，不算当“鹰”。模型里的鹰，是真准备掀桌子、扛损失的。 |
| 这件事——你想想就明白——本质上很简单 | 这件事你想想就明白：本质上很简单 |
| Maltz 借了一个词——servo——来形容 | Maltz 借了一个词，叫 servo |

**Rule:** 正文默认 0 个 `——`（原文引语自带的除外）。不要为了留“呼吸感”硬塞破折号。

## 5. 直译连接词 / Translated connectors

**看连接词承担什么关系，不只看它长得像不像翻译。** 下表是候选，不是逐字替换表。

| 翻译腔 ❌ | 原生中文 ✅ |
|---|---|
| 事实上 / 实际上 | 其实 / 讲白了 / 说白了 |
| 此外 / 另外 | 还有就是 / 而且 |
| 因此 | 所以 |
| 然而 | 可是 / 但 / 可 |
| 换句话说 | 也就是说 / 这么说吧 |
| 与此同时 | 同时 / 顺带 |
| 不仅...而且 | 又...又 / 不光...还 |
| 不是 X，而是 Y | 保留有用的区别；空对比改成直接陈述 |

**Rule:** 只删空转路标或不合口气的连接词。确实表达因果、同时、转折或修正时保留其作用；不要为了口语化换掉逻辑关系。

## 6. 直译 "It's not X. It's Y." 

英文这个对仗句式很常见，中文直译 "这不是 X，这是 Y" 会反复出现，读起来非常机械。先判断否定部分是否纠正真实误解、是否有独立含义。

空对比直接改成陈述；真实区别保留两端意思，再按中文组织。不要用 "X？不是。是 Y。"、"并非"、"其实" 或 "真正" 换壳，让原来的反转结构继续存在。

**Rule:** 整篇文章不超过 2 次 "这不是 X，是 Y"。

不要只换几个字，继续重复同一种翻案腔。读者并没有那个误解时，直接说清楚判断；作者真实的迟疑和改口则保留。

## 6.1 独立检查中文，不只逐句对齐

处理中文时同时读 `../../humanizer/references/zh-editing.md`。先确认每段要说什么，允许重排主语、动作和限定，拆并受影响的句子；再核对事实、观点强弱和引文。最后放下英文，连着读中文，检查搭配与衔接。

“英文里的限定都对应上了”不等于“中文说顺了”。如果仍然需要倒回去找主干，就重新组织整句，不靠再加一个“其实”或“对我来说”解决。

## 6.2 防御性端水腔 / 审稿人免责腔（新型 AI 味）

早期的 AI 味是“端着、吹牛、金句叠罗汉”；现在强模型被安全/准确性规则压过头之后，常出现另一种 AI 味：**每讲完一个观点就补一句免责声明，正反两面反复端水，把文章写得像 HR 通知或学术审稿回复。**

区分两件事：
- **事实诚实（保留）**：某个研究结论学界有争议，或者这只是单家公司的自述，用半句话交代清楚即可。
- **防御废话（删掉）**：“这只是我借模型看现实的角度，收益表本身证明不了这些”“这些只是沟通方式的例子，不能保证对方会好好回应”“一个人已经很辛苦了，我不会拿这段誓言要求他乐观”“我可以在帮别人的同时照顾好自己，也没必要等一边做完再做另一边”。

**Rule:** 观点说清就停，别替抬杠的读者提前打补丁。真实迟疑（“这事我也说不太清”）留着，免责条款删掉。

## 7. Title 翻译腔

中文标题 **不要用 4 字文言成语**（"曳尾涂中"、"知行合一"、"破而后立"）除非文章本身就是讲那个成语。

✅ 现代白话：
- "做一只泥里的乌龟"
- "你不是在找自己，是在写自己"
- "为什么聪明人都在 FIRE"

❌ 太文言：
- "曳尾涂中"
- "无问西东"
- "知止而后有定"

**Rule:** 通俗、清楚，和文章的实际意思一致。不为凑字数改意思；不用与内容无关的文言成语。

## 8. 保留英文术语（区分“口头黑话”与“懒得翻译”）

Zach 说话会自然夹英文，但只夹硅谷/工程语境里真的顺口的词，不把有自然中文说法的日常概念也留在英文里。

**保留英文（顺口）：**
- 工程 / AI / 职场高频词：`servo`、`prompt`、`LLM`、`harness`、`agent`、`persona`、`backlog`、`Slack`、`PR`、`commit`、`bar`、`flag`、`owner`、`review`、`WLB`、`ARR`、`PMF`、`scaling`
- 网络 / 流行词：`i 人` / `e 人`、`BGM`、`IP`、`OKR`、`KPI`、`FIRE`
- 专有名词：人名（Naval, Maltz, Buffett）、英文书名（《Atomic Habits》、《Tools of Titans》）、公司/产品名（Kickstarter、Patreon、McKinsey）

**翻译成中文（别偷懒留英文）：**
- 日常/商业概念：`crowdfunding` → 众筹、`creator` → 创作者、`true fans` → 真爱粉、`outfit check` → 穿搭检查（或直接说照镜子）、`win-win` → 双赢、`chef's table` → 主厨餐桌
- 抽象概念：`identity` → 身份 / 自我形象（不用“认同”）、`execute` → 执行 / 上场、`frustrated` → 烦 / 受不了

**长引文不双贴：** 在中文版里，除非原文措辞本身是讨论对象，否则不要把一整段英文原句贴出来、紧接着在下面逐句翻一遍；直接用自然中文转述或译出即可（必要时留一句短原话）。

**Rule:** Zach 之前的文章里某个词怎么处理过 → 保持一致。

## 9. 段落节奏与双语解耦

中文按自己的意思推进，**不要机械维持和英文 1:1 的段数或句序**。两版只要保住相同的事实、论点、例子和语气强弱就行；英文里拆成两句的地方，中文合并成一句往往更顺，反之亦然。

- 一句话一段是常见的（强调、节奏）
- 两段之间空行，留呼吸
- 长段若换了话题、场景或叙述阶段，可以拆；同一个意思还没讲完，可以接着写

**Rule:** 按意思、衔接和停顿分段，不按句数，也不照搬英文分段。不要为制造参差拆段，也不要把原本自然的段落改得一样齐。

## 10. Self-check（中文部分）

报告 polish 完成前，对中文部分核对：

- [ ] 代词：指代清楚，作者视角与归属没被删掉
- [ ] 嵌套句：主干好理解，条件和限定没被拆散；不按“的”的数量改写
- [ ] 语气词：符合原意和口气，没有为配额硬加
- [ ] 破折号：正文 0 个 `——`（引语自带除外）
- [ ] 连接词：不空转，原有因果、转折、时间关系仍成立
- [ ] "不是 X，是 Y" 对仗：整篇 ≤ 2 次
- [ ] 标题：通俗清楚，意思没变，不为字数凑词
- [ ] 英文术语：保留 Zach 一贯保留的，翻译该翻译的
- [ ] 段落：顺着意思和阅读期待走，没有为句数或参差硬拆
- [ ] 双语对齐：事实、观点强度和第一人称经历一致，但**不是逐句翻译**；不固定英文先写
- [ ] 保留性：按 `preservation-checks.md` 对照前后，没增删事实或改变原有态度
